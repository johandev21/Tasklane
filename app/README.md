# Tasklane web application

The TanStack Start frontend is part of the root Bun workspace. Follow the
repository [setup and commands](../README.md); run frontend commands here with
`bun run <script>`.

The app talks to the Elysia API through the same-origin `/api` and `/ws` Vite
proxies. Authentication uses Better Auth and app data uses Eden Treaty with
TanStack Query.
